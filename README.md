# Animated C++ Alphabet Programs
## About the Project
This project contains C++ programs that draw alphabet letters using stars (`*`) in the Windows console.
## Letters Included
- A — Alphabet A
- B — Alphabet B
- C — Alphabet C
- D — Alphabet D
- E — Alphabet E
- F — Alphabet F
## Concepts Used
- C++ loops (`for`)
- Functions
- Console cursor positioning (`gotoxy`)
- Console text colors
- Animation using `Sleep()`
## Requirements
- Windows operating system
- A C++ compiler, such as Code::Blocks or Visual Studio
## Author
Created as a C++ programming practice project.
